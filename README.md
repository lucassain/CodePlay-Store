## 📌 Overview

CodePlay Store is a console-based digital game store developed in C using modular programming, dynamic memory, file handling, and authentication systems.

The project simulates a real digital marketplace where users can register, buy games, companies can publish products, and administrators can manage the platform.

# 🚀 Features

## 👤 User System
✔ User registration and login  
✔ Email, password and DNI validations  
✔ Profile editing  
✔ Purchase history  
✔ Personal transaction files  

---

## 🏢 Company System
✔ Company registration and authentication  
✔ Publish and manage games  
✔ Edit company information  
✔ Individual company catalogs  

---

## 🎮 Game Catalog
✔ Dynamic game catalog  
✔ Search by name, platform or ID  
✔ Unique game IDs  
✔ Dynamic arrays and resizing  

---

## 💳 Transactions
✔ Purchase processing  
✔ Transaction history  
✔ Revenue reports  
✔ Monthly income reports  
✔ Highest revenue detection  

---

## 🛡️ Admin Panel
✔ Administrator login  
✔ User visualization  
✔ Search users by DNI  
✔ Transaction administration
